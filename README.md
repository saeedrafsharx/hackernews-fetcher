# Hacker News Daily

A simple **FastAPI** app that fetches the 5 newest Hacker News stories once a day and displays them on a static web page.

## Live App

🔗 **URL:** `https://YOUR-APP-URL-HERE`

## Screenshot

![Hacker News Daily](screenshot.png)

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open `http://127.0.0.1:8000`.
